# ZOMEN

موقع ثابت (HTML + CSS + JavaScript فقط، بدون أي Framework أو أدوات بناء) لبيع دورات ZOMEN البرمجية. يعمل بفتح `index.html` مباشرة من أي جهاز، وجاهز للرفع على GitHub Pages.

## كيف تُعدّل الأسعار والعرض ومعلومات الدفع

كل الإعدادات القابلة للتغيير موجودة في ملف واحد: [`assets/js/config.js`](assets/js/config.js). لا تحتاج لتعديل أي صفحة HTML.

- **تاريخ انتهاء العرض:** غيّر قيمة `offerEndDate` (بتوقيت الأردن، مثال: `2026-11-26T23:59:00+03:00`). نص الشارة "عرض لفترة محدودة · حتى الخميس 26/11" يتولّد تلقائياً من هذا التاريخ (اسم اليوم + اليوم/الشهر) في كل الصفحات.
- **الأسعار:** داخل كائن `courses`، لكل دورة:
  - `oldPriceJD` و `oldPriceUSD`: السعر الأصلي.
  - `newPriceJD` و `newPriceUSD`: سعر العرض.
- **سلوك العرض:**
  - قبل `offerEndDate`: السعر الأصلي مشطوب + سعر العرض + الشارة.
  - بعد `offerEndDate`: السعر الأصلي فقط، بدون شطب وبدون شارة.
  
  ينطبق هذا تلقائياً على كروت الدورات في الصفحة الرئيسية، وكرت السعر في صفحات الدورات، وصفحة التسجيل (بما فيها المبلغ المطلوب في كرتَي CliQ وWestern Union).
- **عدد المشكلات البرمجية والتاسكات:** `practice` داخل كل دورة (`value` للرقم و `label` للنص)، ويظهر في كرت قسم "تتضمن الدورة".
- **اسم الدورة في صفحة التسجيل:** `title` داخل كل دورة.
- **معلومات الدفع:** كائن `payment`:
  - `payment.cliq`: رقم CliQ (`number`، يُعرض كما تكتبه وزر النسخ ينسخه بدون فراغات) واسم المستلم (`recipient`).
  - `payment.westernUnion`: الاسم الكامل (`fullName`) والدولة (`country`) والمدينة (`city`).
- **رابط إنستغرام:** غيّر قيمة `instagramLink`، وكل أزرار إرسال الحوالة و"تواصل معنا" في الموقع ستُحدَّث تلقائياً.

### صفحة التسجيل

كل زر "سجّل الآن" في صفحات الدورات يفتح `register.html?course=<slug>` (مثلاً `register.html?course=cpp-fundamentals`). الصفحة تقرأ الـ slug وتعرض اسم الدورة وسعرها من `config.js`. إذا لم يكن في الرابط slug أو كان غير صحيح، تعرض قائمة بالدورات ليختار منها الطالب.

### قيم الـ fallback داخل HTML

الأرقام والنصوص المكتوبة داخل صفحات HTML (الأسعار، أعداد المشكلات، معلومات الدفع) هي قيم احتياطية تظهر فقط إذا تعطّل JavaScript، ويستبدلها JavaScript بالقيم من `config.js` عند فتح الصفحة.

- قيم الأسعار الاحتياطية هي **السعر الأصلي** دائماً، والشارة والسعر المشطوب مخفيّان افتراضياً (`hidden`). لذلك لا يظهر سعر عرض منتهٍ أبداً، حتى بدون JavaScript.
- إذا غيّرت السعر الأصلي أو عدد المشكلات أو معلومات الدفع في `config.js`، يُفضّل تعديل نفس القيمة داخل HTML حتى تبقى متطابقة. أما تغيير سعر العرض أو تاريخه فلا يحتاج أي تعديل في HTML.
- أوصاف الدورات في الـ Hero ووسوم `meta` مكتوبة مباشرة في HTML (مثلاً "50 مشكلة برمجية محلولة" في وصف دورة Java)، فإذا تغيّر العدد عدّله هناك أيضاً.

## كيف تُستبدل صور آراء الطلاب

الصور موجودة في `assets/images/feedback/` بأسماء `feedback-01.jpg` إلى `feedback-08.jpg`. لاستبدال أي واحدة منها:

1. جهّز لقطة الشاشة (Screenshot) الجديدة لرسالة الطالب.
2. احفظها بنفس الاسم (مثلاً `feedback-03.jpg`) في نفس المجلد لتحل محل القديمة تلقائياً، أو غيّر مسار الصورة داخل `index.html` وصفحات الدورات إذا استخدمت اسماً مختلفاً.

## خطوات الرفع على GitHub Pages

1. أنشئ مستودع (Repository) جديد على GitHub.
2. من داخل مجلد المشروع، نفّذ:
   ```bash
   git init
   git add .
   git commit -m "ZOMEN website"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO-NAME.git
   git push -u origin main
   ```
3. من إعدادات المستودع على GitHub: **Settings → Pages → Build and deployment → Source** اختر **Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/ (root)`.
4. بعد بضع دقائق سيكون الموقع متاحاً على:
   ```
   https://USERNAME.github.io/REPO-NAME/
   ```

كل المسارات في الموقع نسبية، لذلك يعمل بشكل صحيح سواء فتحته محلياً أو على رابط فرعي مثل الرابط أعلاه.
